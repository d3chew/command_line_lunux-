-----------КОМАДНАЯ СТРОКА ЛИНУКС-------------
1.1 КОМАДНАЯ ОБОЛОЧКА
'date' - выводит сегоднешнюю текущие время и дату
'cal' - выводит календарь текущего месяца
'df' - показует свободное пространство на дисках 
'free' - показует свободное пространство в памяти
'exit' - завершает сеанс работы 

1.2 НАВИГАЦИЯ 
'pwd' - выводит название текущего каталога в котором мы находимся 
'cd' - смена каталога
'ls' - выводит список файлов и каталогов в текущем рабочем каталоге 
     команда -параметр аргумент 
     1)ls -a (--all) - список всех файлов,даже с именами,начинающимися с точки,которые обычно не выводятся(то есть скрытых)
     2)ls -A (--almost -all) - действует подобные парметру -a,но не выводит каталоги.(текущий рабочий каталог) и 
     ..(родительский каталог)
     3) ls -d (--directory) - обычно в присутствии этого параметра команда ls выводит информацию о самом каталоге,а не о его
     содержимого.Используется этот пааметр в сочетании с параметром -l,чтобы получить дополнительную иннформацию о каталоге,
     а не о его содержимом 
     4)ls -F (--classify) - добавляет в конец каждого имени символ-индикатор (например,прямой слеш,если это имя каталога)
     5)ls -h (human-readable) - при использовании длинного формата,вывода отбражает размеры файлов не в байтах,а в величинах
     с единицами измерения
     6)ls -l - выводит формат результата с использованием длинного формата
     7)ls -r (--reverse) - выводит резьльтат в обратном порядке.Обычно команда ls выводит результат в алфавитном порядке 
     8)ls -S - сортировка результата по размеру (size)
     9)ls -t - сортировка результата по времени (time) последнего изменения 
1.3 ИССЛЕДОВАНИЕ СИСТЕМЫ 
'file' - выводит краткое описание содержимого файла
'less' - программа для просмотра текстовых файлов 
'rm' - удаление файла
'mkdir' - создание каталога 
'mv' - перемещение и переименование файлов 
'ln' - создание ссылок
